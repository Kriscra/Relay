@EventHandler(priority = EventPriority.HIGH, ignoreCancelled = true)
public void onDamage(EntityDamageByEntityEvent event) {
    if (event.getDamager() instanceof Player damager && event.getEntity() instanceof Player victim) {
        RelayAPI.getParties().ifPresent(parties -> {
            // isFriendlySync: O(1) lock-free kontrol. Saniyede binlerce vuruşta thread dondurmaz:
            if (parties.isFriendlySync(damager.getUniqueId(), victim.getUniqueId())) {
                event.setCancelled(true);
                damager.sendMessage("§cTakım arkadaşına saldıramazsın!");
            }
        });
    }
}

Neden Vault Yerine Relay?

13 yıl önceki Spigot kısıtlamaları ile modern Paper/Folia mühendisliği arasındaki farklar.

Özellik & Kriter Vault (Legacy 2011) Relay (Modern Standart)
İş Parçacığı (Threading) Senkron — Main Thread'i bekletip lag yaratır %100 Asenkron (CompletableFuture)
Platform Desteği Tek çekirdekli eski Bukkit / Spigot Paper, Purpur ve Çok Çekirdekli Folia Uyumlu
Finansal Aritmetik double (Kuruş yuvarlama & kaybolma hataları) BigDecimal ile %100 kayıpsız hassasiyet
Para Birimleri Yalnızca 1 tek para birimi Sınırsız Çoklu Para Birimi (Currency standartı)
Eklentiler Arası İletişim Yok — Doğrudan .jar bağımlılığı gerektirir Bağımsız Pub/Sub & Mikroservis RPC EventBus
Yüklenme Sırası (Load Order) NullPointerException (Kritik bağımlılık çöküşü) Reaktif onServiceReady Promise mimarisi
Dost Ateşi & Parti Yönetimi Yok isFriendlySync ile sıfır gecikmeli PVP koruması

Giriş

Genel Bakış & Mimari Tasarım

Relay'in modüler altyapısı ve Paper/Folia odaklı mühendisliği.

Relay, modern Minecraft sunucu yazılımlarında (Paper, Purpur ve özellikle çok iş parçacıklı Folia) eklentiler arası entegrasyonu modern standartlara taşımak için geliştirilmiş açık kaynaklı bir servis çatısıdır.

Eski Bukkit mimarisinde geliştirilen çözümler, her eklentinin birbirinin .jar dosyasına doğrudan bağımlı olmasını veya ana sunucu thread'ini donduran senkron metotlar kullanmasını gerektiriyordu. Relay, mikroservis benzeri Pub/Sub EventBus ve Reaktif Promise Servis Kaydı ile eklentileri tamamen birbirinden bağımsız hale getirir.

Mimarinin Temel Taşı: İki Ayrı Modül
  • relay-api: Yalnızca arayüzleri ve veri modellerini barındıran, 40 KB'lık hafif SDK kütüphanesi. Eklenti geliştiricileri sadece bunu çeker.
  • relay-core: Sunucunun plugins/ klasörüne atılan, motoru STARTUP aşamasında ayağa kaldıran ana eklenti.

Çekirdek Sistem

Dinamik Reaktif Servis Kaydı

Öncelik basamakları ve yüklenme sırası bağımsız servis tüketimi.

Reaktif Servis Tüketimi (onServiceReady)

Eklentinizin ekonomi veya parti eklentisinden önce mi sonra mı yüklendiğini kontrol etmenize gerek yoktur:

RelayAPI.getServiceRegistry().onServiceReady(EconomyService.class, economy -> {
    getLogger().info("Ekonomi sistemi bağlandı! Para birimi: " + economy.getDefaultCurrency().displayName());
});

Öncelikli Servis Sağlama (Register)

// HIGHEST, HIGH, NORMAL, LOW, FALLBACK
RelayAPI.getServiceRegistry().register(
    EconomyService.class,
    new MyCustomEconomyProvider(),
    ServicePriority.HIGH,
    this
);
İletişim Omurgası

Pub/Sub & Soru-Cevap (RPC)

Bağımsız eklentiler arası mikroservis haberleşmesi.

Kanal Mesajı Yayınlama ve Abone Olma

// 1. Veri yayınlayan eklenti:
RelayAPI.getMessenger().publish("clan:levelup", new ClanLevelPayload("Akıncılar", 10), this);

// 2. Dinleyen eklenti (JAR bağımlılığı gerekmez):
RelayAPI.getMessenger().subscribe("clan:levelup", ClanLevelPayload.class, this, ctx -> {
    ClanLevelPayload data = ctx.getPayload();
    getLogger().info(data.clanName() + " klanı seviye atladı!");
});

Çoklu Para Birimli Asenkron Ekonomi

Kayıpsız BigDecimal aritmetiği ve non-blocking bakiye işlemleri.

RelayAPI.getEconomy().ifPresent(econ -> {
    UUID playerId = player.getUniqueId();
    BigDecimal amount = BigDecimal.valueOf(100.50);

    econ.deposit(playerId, amount, "Ödül").thenAccept(res -> {
        if (res.isSuccess()) {
            player.sendMessage("Yeni bakiye: " + econ.format(res.balanceAfter()));

    });
});

Evrensel Bekleme Süresi Motoru

Otomatik TTL tahliyesi ve yüzde ilerleme hesaplaması.

UUID uuid = player.getUniqueId();
String key = "ability:dash";

if (RelayAPI.getCooldowns().hasCooldown(uuid, key)) {
    player.sendMessage("Kalan süre: " + RelayAPI.getCooldowns().formatRemaining(uuid, key));
    return;
}

RelayAPI.getCooldowns().setCooldown(uuid, key, Duration.ofSeconds(10), this, entry -> {
    player.sendMessage("Dash tekrar hazır!");
});

Mimari

Folia & Paralel Çekirdek Güvenliği

Çok çekirdekli dünyalarda veri bütünlüğü.

Folia, dünyayı birbirinden bağımsız çalışan bölgelere (region) böler. Relay içerisindeki tüm veri yapıları (ConcurrentHashMap, CopyOnWrite, Atomic referanslar) Folia'nın çok iş parçacıklı doğasına tam uyumlu olacak şekilde geliştirilmiştir.
